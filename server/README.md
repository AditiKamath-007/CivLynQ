# CivLynQ Server

Backend for CivLynQ app. Uses Express and Groq SDK.

## Setup
1. \`npm install\`
2. Add your Groq API key to \`.env\`
3. \`node index.js\` or \`npm run start\`

## Endpoints
- POST \`/api/generate-questions\`
- POST \`/api/generate-workflow\`
- POST \`/api/ask-helper\`
- POST \`/api/draft-document\`
